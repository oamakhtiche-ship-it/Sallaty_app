Sallaty App:
Sallaty is a mobile application that helps reduce food waste by connecting clients with merchants who want to sell their surplus food at affordable prices.

Features:
Client:

User registration and email verification
Browse and search food offers
Filter offers by price and distance
View offer details
Request offers
Online payment
Chat with merchants
Like offers and follow merchants
Notifications
Ability to become a merchant

Merchant:

Create and manage offers
Manage available quantities
View and manage orders
Chat with clients
Manage merchant profile
Manage followers and liked offers

Admin:

Manage users
Manage merchants and merchant verification
Manage offers
Manage orders
Manage notifications and warnings
Manage platform settings

Technologies:
Frontend: Flutter / Dart

Backend: Java / Spring Boot

Database: MySQL

Services: Firebase

Deployment: Railway

Version Control: Git / GitHub
